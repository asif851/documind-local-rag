Retrieval-Augmented Generation (RAG) is a technique that combines a retrieval system with a language model. Instead of relying only on what the model memorized during training, RAG first searches an external knowledge base for passages relevant to the user's question, then passes those passages to the model as context. This reduces hallucinations, allows answers based on private or up-to-date documents, and makes it possible to cite sources.

A typical RAG pipeline has four steps. First, documents are split into small chunks. Second, each chunk is converted into a numeric vector called an embedding. Third, at question time the query is embedded and the most similar chunks are found using a vector index such as FAISS. Fourth, the retrieved chunks are inserted into the prompt and the language model writes the final answer.
